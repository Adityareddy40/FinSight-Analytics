# FinSight-Analytics
# Financial Performance Analytics Dashboard

## Project Overview

This project analyzes sales, profitability, regional performance,
product performance and financial trends using Excel, Python and Tableau.

## Tools Used

- Microsoft Excel
- Python
- Pandas
- NumPy
- Matplotlib
- Tableau

## Project Workflow

Excel
   ↓
Data Cleaning
   ↓
Python EDA
   ↓
Financial Analysis
   ↓
Tableau Dashboard
   ↓
Business Insights

## Key KPIs

- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Total Quantity
- Average Order Value
